Questions have:
1. id: An identifier for each question
2. Language: Java, Python, JavaScript, C++, etc
3. Type: Multiple Choice, Written, Matching
4. Difficulty: Easy, Medium, Hard
5. Question: The actual question
6. Options:
    a. If multiple choice or matching, there are a list of possible solutions
    b. If written, there is only one possible answer
7. Solution: The answer to the question
8. Tags: Is this an internship kind of question or something like that
